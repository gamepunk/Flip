Flip 隐私政策

更新日期：2026-11-13

Flip 是本地优先的 macOS 菜单栏工具。除试用与 License 验证外，不采集使用行为，不建立用户画像。

本地数据

试用起始时间、剩余天数、License Key、菜单栏控制项顺序和快捷键保存在本机的 Application Support 与偏好设置中。删除 App 或相关文件可能导致试用/License 状态丢失。

License 验证

输入 License 时，Flip 会把 License Key、设备名称、App 版本和 macOS 版本发送给 Lemon Squeezy 的 License API，用于激活、续验和停用设备。不会上传原始硬件 UUID 或其他文件。

自动更新

Flip 使用 Sparkle 检查更新，会请求 GitHub Pages 上的 appcast 和更新包。更新源只会收到常规的 HTTP 请求信息。

权限

辅助功能、自动化、蓝牙、专注状态等权限只在对应开关首次使用时请求；拒绝授权不会影响其他功能。

联系

如对隐私有疑问，请通过 Release 仓库 Issues 联系。
